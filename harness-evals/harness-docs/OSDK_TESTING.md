# Operator SDK Testing Guide

## Test Framework

- **Unit/integration tests**: Ginkgo v2 + Gomega
- **Dot imports**: Allowed only for `ginkgo` and `gomega` in test files
- **Build tag**: Always use `-tags containers_image_openpgp`
- **Race detection**: Unit tests run with `CGO_ENABLED=1 -race`

## Test Commands

| Command | Scope | Cluster Required |
|---|---|---|
| `make test-unit` | Unit tests (excludes `test/` directory) | No |
| `make test-sanity` | Format, lint, license, error format, `git diff` | No |
| `make test-static` | Sanity + unit + docs | No |
| `make test-docs` | Changelog validation, link checks | No |
| `make test-e2e` | Full e2e suite | Yes (KIND) |
| `make test-e2e-go` | Go operator e2e | Yes |
| `make test-e2e-helm` | Helm operator e2e | Yes |
| `make test-e2e-integration` | Integration tests | Yes |
| `make verify-file FILE=path` | Single package: fmt, vet, lint, tests | No |

## Test Layout

```
test/
  e2e/go/         # Go operator E2E tests
  e2e/helm/       # Helm operator E2E tests
  integration/    # Integration tests
  common/         # Shared Ginkgo specs
```

Unit tests live alongside the code they test in the `internal/` packages.

## Unit Testing Patterns

### Table-Driven Tests

```go
tests := []struct {
    name    string
    input   string
    want    string
    wantErr bool
}{
    {"valid input", "foo", "bar", false},
    {"empty input", "", "", true},
}
for _, tt := range tests {
    t.Run(tt.name, func(t *testing.T) {
        got, err := Function(tt.input)
        if (err != nil) != tt.wantErr {
            t.Errorf("unexpected error: %v", err)
        }
        if got != tt.want {
            t.Errorf("got %q, want %q", got, tt.want)
        }
    })
}
```

### Fake Clients

Counterfeiter-generated fakes live in `*fakes/` directories. Do not hand-edit. Regenerate with `go generate ./...` (part of `make generate`).

For controller-runtime tests, use `sigs.k8s.io/controller-runtime/pkg/client/fake` to build a fake client with scheme and initial objects.

## E2E Testing

E2E tests require a KIND cluster:

```bash
make test-e2e-setup    # Create KIND cluster, build images, install tools
make test-e2e          # Run all e2e tests
make test-e2e-teardown # Delete KIND cluster
```

The KIND version is pinned to 0.29.0 and Kubernetes to 1.33.1.

`setup-envtest` is pinned to v0.21.0 (matching controller-runtime).

## Test Data

`testdata/` is generated by `make generate` and must not be hand-edited. CI enforces this with `git diff --exit-code` after generation.

## Writing Tests for New Code

1. Add unit tests in the same package.
2. Use Ginkgo/Gomega for async assertions and BDD-style specs.
3. Run `make verify-file FILE=path/to/your/file.go` for fast feedback.
4. Run `make test-unit` before pushing.
5. Add e2e tests in `test/e2e/` if the change affects user-facing behavior.
